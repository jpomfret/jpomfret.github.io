# Code is MIT, content is CC BY-NC-SA 4.0

The repository licenses code and prose differently: templates and code under **MIT** (root `LICENSE`), blog post content under **CC BY-NC-SA 4.0** (`article.license.default` in `params.toml`). The intent is that the *code* is freely reusable by anyone, while the *writing* requires attribution, may not be commercially repackaged, and any derivative stays under the same terms. The content clauses were inherited from the theme starter and consciously retained rather than picked clause-by-clause, but the split itself — adding a root MIT file for code while keeping the content license — was a deliberate decision made during the rebrand. Recorded here because a single-license repo is the default assumption, and CLAUDE.md/DESIGN.md previously drifted on whether the license was "inherited" or "deliberate."
