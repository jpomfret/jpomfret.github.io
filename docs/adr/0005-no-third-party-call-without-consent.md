# No third-party network call fires without consent

No external network request runs on page load without the visitor's consent. Google Analytics is not included in `<head>`; it loads only after an explicit "Accept" in the cookie-consent banner (`footer/custom.html`), with the choice persisted in `localStorage` and `anonymize_ip: true`. The brand fonts are self-hosted specifically so no Google Fonts request is ever made, and the theme's default Google-Fonts include (`custom-font.html`) is overridden to a no-op. The trigger was cookie-consent law, but the implementation deliberately goes further than compliance strictly requires (killing the fonts call entirely, anonymizing IPs). Recorded because the several no-op overrides and the gated GA loader look like omissions or breakage unless you know they're intentional.
